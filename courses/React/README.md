# React Gym

React Gym is my personal workspace for learning and practicing React as part of my self-directed Computer Science education through the OSSU curriculum.

This repository is not intended to be a polished React project. Instead, it serves as a place to:

- Practice React concepts one exercise at a time
- Record common mistakes and lessons learned
- Experiment with new ideas before using them in larger projects
- Build a personal React reference for future review

## Primary Resource

My primary learning resource is Codecademy's **Learn React** course.

At the time this repository was created, the course is available **free of charge**, although Codecademy also offers optional paid subscriptions with additional features such as projects, career paths, and certificates.

Course:

https://www.codecademy.com/learn/react-101

## Repository Goals

- Learn React fundamentals thoroughly
- Understand *why* code works, not just *how* to write it
- Develop good coding habits, including clear code comments
- Build confidence through repetition and small practice exercises

## Notes

Many examples in this repository are intentionally small and focused on a single concept. The goal is understanding, experimentation, and long-term retention rather than building complete applications.

As my React knowledge grows, this repository will become a personalized reference guide documenting what I learned, mistakes I made, and the mental models that helped concepts finally click.
