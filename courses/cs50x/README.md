# CS50x: Introduction to Computer Science

## Overview

CS50x is Harvard University's introduction to the intellectual enterprises of computer science and the art of programming. It serves as the introductory course for the OSSU Computer Science curriculum and provides a broad foundation in computational thinking, algorithms, programming, and software development.
